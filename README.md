# 🌌 Helldivers 2 Wiki-gg Assets Scraper

헬다이버즈 2(Helldivers 2)의 풍부하고 퀄리티 높은 장비 자산(부스터, 망토, 헬멧, 방어구, 스트라타젬, 무기)들의 아이콘 및 렌더 이미지를 [helldivers.wiki.gg](https://helldivers.wiki.gg/) 위키피디아로부터 자동 크롤링하고 고화질 **WebP** 포맷으로 일괄 수집하는 다목적 파이썬 스크래퍼 프로젝트입니다.

---

## 🛠️ 필수 요구 사항 및 라이브러리 설치

### 1. 프로그램 사전 설치

- **Python 3.8** 이상 버전
- **Google Chrome** 브라우저 (Selenium 구동용)

### 2. 의존성 라이브러리 설치

파이썬 패키지 관리자(`pip`)를 사용하여 스크래퍼가 필요로 하는 아래 라이브러리들을 설치합니다.

```bash
pip install selenium pillow svglib reportlab
```

## 🚀 사용 방법

`main.py` 파일은 실행 방식(더블클릭 또는 명령줄 실행)에 따라 자동으로 최적화된 모드를 제공합니다.

### 방법 A. 마우스 더블클릭 실행 (대화형 모드)

터미널을 열지 않고 `main.py` 파일을 마우스로 **더블클릭**하여 손쉽게 동작시키는 방법입니다.

1. `main.py`를 실행하면 콘솔 창이 켜지고 아래와 같은 선택 메뉴가 출력됩니다.
   ```text
   ============================================================
     Helldivers 2 Wiki-gg Scraper - 대화형 실행 모드
   ============================================================
     [1] 전체 카테고리 수집 (All)
     [2] 부스터 (Booster) 수집
     [3] 망토 (Cape) 수집
     [4] 헬멧 (Helmet) 수집
     [5] 방어구 (Armor) 수집
     [6] 스트라타젬 (Stratagems) 수집
     [7] 무기 (Weapon) 수집
     [0] 프로그램 종료
   ============================================================
   ```
2. **원하는 수집 번호를 입력**하고 엔터를 누릅니다.
   - 전체 수집은 `1`을 입력합니다.
   - 부분 다중 선택은 콤마(쉼표)로 구분하여 `2,4,6`과 같이 입력할 수 있습니다.
3. 백그라운드에서 크롬창을 보이지 않게 실행할지 여부(`Y/n`)를 선택합니다.
4. 커스텀 저장 공간을 원하시면 저장할 폴더명을 입력하고, 그렇지 않으면 그냥 엔터를 누릅니다 (현재 스크립트 실행 디렉토리에 한글 폴더로 알아서 생성 및 분류됩니다).
5. 수집이 완전히 완료되면 창이 바로 닫히지 않고 대기 상태로 유지되므로 눈으로 확인하신 뒤 엔터를 눌러 안전하게 종료해 주세요.

---

### 방법 B. 명령줄 터미널 실행 (CLI 모드)

개발자 혹은 커맨드라인 환경에서 정교하게 스크래핑을 일괄 자동화하고 싶을 때 유용한 방식입니다.

#### 1. 명령어 도움말 확인

```bash
python main.py --help
```

#### 2. 사용 가능한 명령어 옵션

| 옵션            | 단축 옵션 | 설명                                                                 | 기본값                        |
| :-------------- | :-------- | :------------------------------------------------------------------- | :---------------------------- |
| `--all`         | -         | 전체 카테고리를 순서대로 전부 일괄 수집합니다.                       | `False`                       |
| `--output`      | `-o`      | 수집한 이미지들이 저장될 출력 기본 폴더 경로를 지정합니다.           | 스크립트 실행 위치            |
| `--cache`       | `-c`      | 중복 다운로드를 체크하는 캐시 텍스트 파일 경로를 직접 지정합니다.    | `[출력폴더]/downloaded_*.txt` |
| `--no-headless` | -         | 백그라운드 모드를 끄고 Chrome 창 화면을 직접 보면서 동작하게 합니다. | Headless (창 안 보임)         |
| `--workers`     | `-w`      | 이미지 동시 병렬 다운로드를 수행할 최대 멀티프로세싱 프로세스 수     | `4`                           |

#### 3. CLI 실행 예시

- **모든 항목 백그라운드로 전수 자동 크롤링**:
  ```bash
  python main.py --all
  ```
- **부스터와 방어구만 특정 폴더에 커스텀 다운로드**:
  ```bash
  python main.py booster armor --output "D:\HD2_Assets"
  ```
- **수집 과정을 브라우저 화면으로 직접 실시간 관찰하며 수집**:
  ```bash
  python main.py stratagems weapon --no-headless
  ```

## 📁 자동 생성 및 수집되는 폴더 구조

다운로드가 시작되면 스크래핑한 WebP 파일들은 지정 폴더 하위에 아래의 깔끔하게 분할된 한글 디렉토리 구조로 알아서 수집됩니다.

```text
📁 [출력 디렉토리]
├── 📁 부스터/           # (예: Stamina_Enhancement_Booster_Icon.webp 등)
├── 📁 망토/             # (망토 렌더 이미지 약 85종)
├── 📁 헬멧/             # (헬멧 렌더 이미지 약 97종)
├── 📁 방어구/
│   ├── 📁 경량/         # (경량 갑옷 세트 약 29종)
│   ├── 📁 일반/         # (일반 갑옷 세트 약 48종)
│   └── 📁 중량/         # (중량 갑옷 세트 약 26종)
├── 📁 공격/             # (오비탈, 이글 스트라타젬 약 30종)
├── 📁 방어/             # (센트리, 진지 설치물 스트라타젬)
├── 📁 보급/             # (지원 무기, 배낭, 차량 스트라타젬)
├── 📁 임무/             # (임무 목적성 스트라타젬)
└── 📁 주 무기/
    ├── 📁 돌격 소총/
    ├── 📁 기관단총/
    └── ... (종류별 분할 저장)
```
